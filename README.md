## In Memoriam

> The following forks served faithfully in their time. Some taught us JavaScript when we were young. Others simply existed, quietly, asking nothing, contributing less. We honour them here, one final time, before they return to the upstream from whence they came.

### JS / React (The Class of 2016-2018)


**[babel](https://github.com/babel/babel)** — We forked the actual Babel compiler. 47,000 stars. We added nothing. This was the GitHub equivalent of standing next to a celebrity and hoping someone takes a photo.

**[coreui-free-react-admin-template](https://github.com/coreui/coreui-free-react-admin-template)** — Bootstrap 4. React. Admin dashboard. You had everything a 2017 side project needed, except a side project.

**[cosmos](https://github.com/react-cosmos/react-cosmos)** — A React component playground. Truly encapsulated. So encapsulated, in fact, that we never opened it.

**[create-react-app](https://github.com/facebook/create-react-app)** — Promised zero configuration. Delivered zero maintenance. Even Facebook walked away. You were everyone's first React app and nobody's last.

**[deco-ide](https://github.com/decosoftware/deco-ide)** — The React Native IDE. The company behind you shut down. You were too beautiful for this world, or at least too beautiful for Series A funding.

**[js-stack-from-scratch](https://github.com/verekia/js-stack-from-scratch)** — Step-by-step tutorial to build a modern JavaScript stack. Published 2017. The stack is no longer modern. The steps lead nowhere.

**[modern-js-cheatsheet](https://github.com/mbeaudru/modern-js-cheatsheet)** — Modern in 2017. Archaeological in 2026. "var" is mentioned unironically.

**[node-cluster-tutorial](https://github.com/behroozk/node-cluster-tutorial)** — A tutorial about Node.js clustering. One cluster. One tutorial. One fork. Zero returns.

**[react-hot-boilerplate](https://github.com/gaearon/react-hot-boilerplate)** — Dan Abramov's gift to the world: live-reloading React before it was cool. You were minimal, elegant, and deprecated before your README finished loading.

**[react-redux-links](https://github.com/markerikson/react-redux-links)** — A curated list of links we bookmarked, inside a repo we forked, inside a browser we never closed. Bookmarks all the way down.

**[react-static-site](https://github.com/BradDenver/react-static-site)** — An experiment in generating static sites from React. The experiment concluded. The results were not published.

**[react-universal](https://github.com/cdebotton/react-universal)** — Universal React, they said. Server-side rendering, they said. Then Next.js arrived and you were just... a starter kit nobody started with.

**[reactotron](https://github.com/infinitered/reactotron)** — You helped us inspect React Native apps during that brief, glorious period when we believed React Native was the future. Infinite Red made you well. We just never used you.

**[You-Dont-Need-jQuery](https://github.com/camsong/You-Dont-Need-jQuery)** — Correct. We also didn't need this fork. jQuery is dead and this repo is its headstone.

### Android / Java (The Udacity Years)


**[Android-CleanArchitecture](https://github.com/android10/Android-CleanArchitecture)** — Uncle Bob's Clean Architecture, demonstrated on Android. The architecture was clean. Our understanding of it was not.

**[android-fundamentals](https://github.com/google-developer-training/android-fundamentals)** — Google's own Android training. Fundamental in 2015. Fossilised in 2026. Jetpack Compose sends its regards.

**[android_guides](https://github.com/codepath/android_guides)** — CodePath's extensive open-source Android guides. Extensive. Open. Never read past the RecyclerView section.

**[AndroidAssetStudio](https://github.com/romannurik/AndroidAssetStudio)** — A web tool for generating Android assets. It runs in a browser. It never needed to be forked. We forked it anyway. Youth.

**[AppListLoader](https://github.com/alexjlockwood/adp-applistloader)** — Part 4 of a tutorial series. We don't remember parts 1 through 3. We don't remember part 4 either.

**[astrid](https://github.com/todoroo/astrid)** — The original Astrid task manager. You died so that tasks/tasks could live. Your sacrifice is noted in the curated section above.

**[Code4Reference](https://github.com/rakeshcusat/Code4Reference)** — "Code which can be referred as example code, written for learning purpose." We have stopped learning from it. The reference is now to a time we cannot return to.

**[cue.language](https://github.com/jdf/cue.language)** — A small Java library for text analysis. Counting strings and removing stop words. Small in scope. Smaller in impact. Smallest in our memory.

**[dagger](https://github.com/square/dagger)** — Square's original dependency injector. Replaced by Dagger 2 from Google. Even the maintainers moved on. We forked v1. Loyalty.

**[DataBindingExample](https://github.com/stfalcon-studio/DataBindingExample)** — An example of Android data binding. Example noted. Example archived. Example forgotten.

**[EnvayaSMS](https://github.com/youngj/EnvayaSMS)** — An SMS gateway for Android. Gateway to where, we never asked. Gateway to here, it turns out: the bottom of a bookmarks file.

**[ForceClose](https://github.com/hardik-trivedi/ForceClose)** — An Android tutorial project named ForceClose. The name became self-fulfilling.

**[fork](https://github.com/shazam/fork)** — A repo literally named "fork." From Shazam. For Android test execution. The name aged perfectly for this occasion.

**[greenDAO](https://github.com/greenrobot/greenDAO)** — Light and fast ORM for Android. Room replaced it. The light went out. The room moved on.

**[java-design-patterns](https://github.com/iluwatar/java-design-patterns)** — Design pattern samples in Java. We now prefer design-patterns-for-humans, which explains them without making us write Java.

**[kodkod](https://github.com/emina/kodkod)** — A solver for relational logic. We could not solve the relational logic of why we forked this.

**[lombok](https://github.com/projectlombok/lombok)** — Spicy additions to Java. We no longer write Java. The spice has faded.

**[PD-classes](https://github.com/watabou/PD-classes)** — Simple game library for Pixel Dungeon. The dungeon persists, but we no longer delve.

**[RFAnalyzer](https://github.com/demantz/RFAnalyzer)** — HackRF spectrum analyzer for Android. We owned a HackRF once. It's in a drawer. This fork is the digital equivalent of that drawer.

**[roboguice](https://github.com/roboguice/roboguice)** — Google Guice on Android. Then Dagger came. Then Dagger 2. Then Hilt. RoboGuice was the grandfather who saw too many successors.

**[SlidingMenu](https://github.com/jfeinstein10/SlidingMenu)** — The sliding hamburger menu library. Deprecated. The hamburger menu itself is now considered a UX crime. Double deprecated.

**[sms-backup-plus](https://github.com/jberkel/sms-backup-plus)** — Backed up SMS to Gmail. From the era when people sent SMS and used Gmail. Both technically still exist, like this fork.

**[Sunshine](https://github.com/smeise/Sunshine)** — The other Sunshine. Probably a typo fix. Even the sun sets.

**[Sunshine-Version-2](https://github.com/udacity/Sunshine-Version-2)** — The Udacity Android weather app. Taught us Activities, Intents, and the quiet despair of Android XML layouts. You showed us the sun, then we moved to iOS, then we moved to Python.

**[SwarmSim](https://github.com/djcrock/SwarmSim)** — A swarm simulation game. The swarm has dispersed.

**[SWFREtools](https://github.com/sporst/SWFREtools)** — SWF reverse engineering tools. Flash is dead. Adobe killed it. The browser vendors buried it. This fork is the flowers on the grave.

**[WishListManager](https://github.com/justadreamer/WishListManager)** — An ORMLite tutorial for managing wish lists on Android. Our wish to never write ORMLite again has been granted.

### Laid to Rest

> These forks served with distinction in the security research wing. They are not curated here due to the impression they leave on a public profile, but their contributions to our education are acknowledged.


**[fluxion](https://github.com/samyoyo/flux)** — WiFi security auditing tool. Something was built here. Back it up before it goes.

**[ibrute](https://github.com/hackappcom/ibrute)** — iCloud brute force. From the Fappening era. Educational then. Indefensible now on a public profile.

**[Mirai-Source-Code](https://github.com/jgamblin/Mirai-Source-Code)** — The IoT botnet that took down Dyn DNS in 2016. We studied it. We learned from it. Recruiters will not understand that nuance.

**[pldtfibr-wifi-password](https://github.com/srph/pldtfibr-wifi-password)** — Reversed the default password algorithm for PLDT Fibr routers. Clever. Filipino. Pragmatic. Also technically unauthorized access to someone else's network.

**[SpoofMAC](https://github.com/feross/SpoofMAC)** + **[spoof](https://github.com/feross/spoof)** — MAC address spoofing. Useful for debugging. Also useful for things that are not debugging.
